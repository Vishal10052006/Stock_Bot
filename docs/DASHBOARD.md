# STOCK_BOT Ops Center Dashboard

The dashboard is a single-file operator UI modeled on the project operations-center reference: left navigation, pipeline trace, agent roster, contract/protocol state, telemetry stream, system health, decision inspection, model observability, and controlled self-learning.

## Files

- `dashboard/index.html` — dependency-free dashboard UI.
- `dashboard/demo_snapshot.json` — safe demo payload.
- `.github/workflows/dashboard-pages.yml` — deploys the dashboard through GitHub Pages when the repository Pages environment is enabled.

## Data boundary

The dashboard is an **observational consumer** of the existing MonitoringRuntime dashboard JSON contract. It does not create a second monitoring engine.

Use **LOAD JSON** to load a snapshot generated by the repository's monitoring runtime.

The default UI is explicitly marked:

- TELEMETRY: DEMO
- ENV: RESEARCH/PAPER
- LIVE: LOCKED
- NO ORDER AUTHORITY

The demo values are visual/replay fixtures, not live trading claims.

## Operator views

1. **Overview** — pipeline trace, agent roster, contract, telemetry, learning loop and health.
2. **Agents** — agent-by-agent operational state.
3. **Pipeline Trace** — Research → Analysis → Market → Prediction → Strategy → Risk → Execution.
4. **Decision Inspector** — decision-time payload inspection.
5. **Model Observability** — model metrics from the loaded snapshot.
6. **System Health** — component health and lock states.
7. **Learning Loop** — trade outcome → error analysis → experience → dataset update → retraining → OOS validation → promotion gate.
8. **Event Log** — telemetry/replay events.

## Safety

The dashboard cannot:

- authorize a trade;
- modify Strategy or Risk state;
- submit broker orders;
- unlock live execution;
- promote a model.

GitHub Pages deployment only serves the static UI.

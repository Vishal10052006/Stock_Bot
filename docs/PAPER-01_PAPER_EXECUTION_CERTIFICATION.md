# PAPER-01 — Paper Execution Certification\n\n## Purpose\n\nPAPER-01 is the deterministic certification layer after the E0–E17 execution implementation. It validates that the existing broker-neutral execution stack behaves correctly in paper mode across normal execution, failure recovery, reconciliation, observability, and safety controls.\n\n**Live broker execution remains locked.** This certification performs no live order submission and does not grant live-execution approval.\n\n## Certification matrix\n\n| Case | Required behavior |\n|---|---|\n| Full fill | Requested quantity becomes fully filled with a canonical fill |\n| Partial fill | Filled quantity remains below requested quantity and state is PARTIALLY_FILLED |\n| Broker rejection | Result is REJECTED_BROKER and is not accepted |\n| UNKNOWN recovery | Submission ambiguity becomes UNKNOWN; recovery queries broker truth and never blindly resubmits |\n| Duplicate replay | Same client order identity returns the original broker order without a second order |\n| Restart recovery | A new engine rehydrates state from broker truth and can reconcile the order |\n| Signed position reconciliation | Matching long/short signed positions are safe; mismatches are blocked |\n| Monitoring + soak | Execution metrics are recorded and deterministic paper soak completes without UNKNOWN orders |\n| Backtest parity + controls | Execution assumptions match backtest assumptions and independent kill-switch/runbook controls pass |\n\n## Implementation\n\n`execution/paper_certification.py` exposes:\n\n- `PaperCertificationCase`\n- `PaperCertificationReport`\n- `run_paper_certification(order_factory)`\n\nThe harness composes existing execution and production-control primitives rather than creating a second execution path.\n\n## Evidence required before the next gate\n\n1. Local/CI execution of `tests/execution/test_paper_certification.py`.\n2. Execution-engine regression remains green.\n3. Full repository regression remains green.\n4. The certification report contains no failed cases.\n5. Live Upstox remains disabled/locked.\n\nPAPER-01 is therefore a **paper certification milestone**, not a declaration of live trading readiness.
